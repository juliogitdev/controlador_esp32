# Referência de componente sensor

Os drivers desta pasta foram retirados do firmware do controlador IR. Eles ilustram ISensor e as leituras de BME280/presença/simulação, mas não constituem um firmware de sensor completo.

Um futuro nó sensor terá identidade, transporte e ciclo de vida próprios, publicando eventos no contrato de fontes. O controlador de ar não inclui estes arquivos nem depende das bibliotecas Adafruit. Para simulação independente utilizável agora, abra tools/sensor-simulator/index.html.
