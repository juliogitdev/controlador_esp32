# Aplicacao web

Esta pasta sera usada para a aplicacao web do projeto, separada do firmware do ESP32.

- `backend/`: API, persistencia, integracao com dispositivos e regras futuras.
- `frontend/`: painel web usado pelos administradores.

## Estado atual

Estrutura inicial criada para planejamento. Tecnologias, dependencias, contratos internos e estrategia de deploy ainda serao definidos antes da implementacao.
